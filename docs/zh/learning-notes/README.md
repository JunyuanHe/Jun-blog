这里是我在学习过程中整理 Markdown 笔记的地方。

笔记主要以英文撰写。如果您需要阅读相关内容，可以点击页面右上角的语言切换按钮，进入英文版页面，即可查看。

英文版与中文版内容相互独立，彼此不完全对应。如因此造成不便，还请谅解。由于时间有限，我无法为每一篇文章或笔记都同时提供中英文版本。因此，若文章以英文撰写，则会发布在英文版中；若以中文撰写，则会发布在中文版中。部分内容可能会有双语版本，但并非全部。

This is where I put my markdown notes during learning.

Note are mostly written in English. So, if you want to read, go to the language button at the up-right of the page to change to English version. You'll see the notes.

The English version and the Chinese version are separate. I apologize if this has lead to any confusion. But I don't have time to write both English and Chinese versions of every blog or note I post. So, if the post is written in English, I will put it in the English version of the blog; if it is Chinese, I will put it in the Chinese version. Some but not all blogs have versions in both languages.
