## **计算机网络模块 — 选择题 50题**

### **TCP/IP 与网络基础（1-10）**

1. 下列哪一项属于 TCP/IP 五层模型？
   
   - A. 应用层
   - B. 表示层
   - C. 会话层
   - D. 物理层
   
   **答案：A, D**
   
   **解析：** TCP/IP 五层：应用、传输、网络、数据链路、物理。

2. TCP/IP 模型中负责逻辑寻址和路由的是？
   
   - A. 应用层
   - B. 传输层
   - C. 网络层
   - D. 数据链路层
   
   **答案：C**

3. 下列属于网络层协议的是？
   
   - A. IP
   - B. TCP
   - C. UDP
   - D. HTTP
   
   **答案：A**

4. 下列属于传输层协议的是？
   
   - A. IP
   - B. TCP
   - C. ARP
   - D. ICMP
   
   **答案：B**

5. 在 TCP/IP 模型中，数据从一台主机传到另一台主机，封装顺序正确的是？
   
   - A. 应用层 → 传输层 → 网络层 → 数据链路层 → 物理层
   - B. 物理层 → 数据链路层 → 网络层 → 传输层 → 应用层
   - C. 应用层 → 网络层 → 传输层 → 数据链路层 → 物理层
   - D. 应用层 → 数据链路层 → 网络层 → 传输层 → 物理层
   
   **答案：A**

6. IP 地址是？
   
   - A. 物理地址
   - B. 逻辑地址
   - C. 广播地址
   - D. MAC 地址
   
   **答案：B**

7. 下列哪一项属于数据链路层功能？
   
   - A. 错误检测
   - B. 流量控制
   - C. 逻辑寻址
   - D. 路由选择
   
   **答案：A, B**

8. MAC 地址用于？
   
   - A. 网络层寻址
   - B. 数据链路层寻址
   - C. 应用层识别
   - D. 传输层识别
   
   **答案：B**

9. 下列哪种是 IPv4 地址表示方式？
   
   - A. 32 位二进制
   - B. 128 位二进制
   - C. 64 位二进制
   - D. 16 位二进制
   
   **答案：A**

10. IPv6 地址长度是？
    
    - A. 32 位
    - B. 64 位
    - C. 128 位
    - D. 256 位
    
    **答案：C**

### **TCP / UDP（11-20）**

11. TCP 是面向连接的协议，原因是？
    
    - A. 使用三次握手建立连接
    - B. 无需确认数据
    - C. 不保证顺序
    - D. 数据报独立发送
    
    **答案：A**

12. UDP 是无连接协议，它的特点包括？
    
    - A. 不可靠
    - B. 面向报文
    - C. 有序传输
    - D. 低开销
    
    **答案：A, B, D**

13. TCP 传输的特点不包括？
    
    - A. 顺序可靠
    - B. 流量控制
    - C. 无连接
    - D. 拥塞控制
    
    **答案：C**

14. 下列哪种属于 TCP 的可靠传输机制？
    
    - A. 序列号
    - B. 确认应答（ACK）
    - C. 超时重传
    - D. 三次握手
    
    **答案：A, B, C, D**

15. UDP 常用于以下哪种应用？
    
    - A. 视频直播
    - B. 文件传输（FTP）
    - C. HTTP 网页访问
    - D. SMTP 邮件
    
    **答案：A**

16. TCP 如何防止网络拥塞？
    
    - A. 拥塞窗口（Congestion Window）
    - B. 流量控制
    - C. FIFO 队列
    - D. CRC 校验
    
    **答案：A, B**

17. TCP 三次握手中，第二次握手发送的包包含？
    
    - A. SYN
    - B. SYN + ACK
    - C. ACK
    - D. FIN
    
    **答案：B**

18. TCP 四次挥手中，主动关闭的一方先发送？
    
    - A. FIN
    - B. ACK
    - C. SYN
    - D. PSH
    
    **答案：A**

19. 下列说法正确的是？
    
    - A. TCP 适合文件传输
    - B. UDP 适合实时通信
    - C. TCP 不可靠
    - D. UDP 必须三次握手
    
    **答案：A, B**

20. TCP 连接中，接收窗口的作用是？
    
    - A. 控制数据流量
    - B. 提高带宽
    - C. 防止死锁
    - D. 用于路由选择
    
    **答案：A**

### **HTTP / HTTPS（21-30）**

21. 下列关于 HTTP 的说法正确的是？
    
    - A. 无状态协议
    - B. 面向连接
    - C. 可靠传输
    - D. 使用 TCP
    
    **答案：A, D**

22. HTTPS 相比 HTTP 主要优势是？
    
    - A. 数据加密
    - B. 身份认证
    - C. 数据完整性
    - D. 更高传输速度
    
    **答案：A, B, C**

23. HTTP/1.1 与 HTTP/2 区别主要是？
    
    - A. HTTP/2 支持多路复用
    - B. HTTP/2 使用二进制帧
    - C. HTTP/1.1 默认无加密
    - D. HTTP/1.1 不支持 TCP
    
    **答案：A, B**

24. HTTP 状态码 200 表示？
    
    - A. 成功
    - B. 重定向
    - C. 客户端错误
    - D. 服务器错误
    
    **答案：A**

25. HTTP 状态码 404 表示？
    
    - A. 成功
    - B. 未找到资源
    - C. 内部服务器错误
    - D. 请求超时
    
    **答案：B**

26. HTTP 状态码 500 表示？
    
    - A. 成功
    - B. 未找到
    - C. 服务器内部错误
    - D. 客户端请求错误
    
    **答案：C**

27. HTTPS 中 SSL/TLS 的主要作用是？
    
    - A. 数据加密
    - B. 防止中间人攻击
    - C. 验证服务器身份
    - D. 提高网页访问速度
    
    **答案：A, B, C**

28. HTTP 请求方法 GET 的特点是？
    
    - A. 请求数据包含在 URL 中
    - B. 对服务器无副作用
    - C. 可缓存
    - D. 必须使用 POST
    
    **答案：A, B, C**

29. 下列方法属于 HTTP 的安全方法是？
    
    - A. GET
    - B. POST
    - C. PUT
    - D. DELETE
    
    **答案：A, B, C, D**
    
    **解析：** 这里“安全”指可被加密保护；实际 GET/POST 常用。

30. HTTP Keep-Alive 的作用是？
    
    - A. 维持 TCP 连接
    - B. 提高请求效率
    - C. 节省握手开销
    - D. 防止丢包
    
    **答案：A, B, C**

### **网络层与路由（31-40）**

31. IP 数据报头中不包含？
    
    - A. 源 IP
    - B. 目的 IP
    - C. 序列号
    - D. TTL
    
    **答案：C**

32. 路由选择算法常用的有？
    
    - A. 最短路径算法（Dijkstra）
    - B. 距离向量算法（Bellman-Ford）
    - C. 贪心算法
    - D. 堆排序
    
    **答案：A, B**

33. 静态路由的特点是？
    
    - A. 手动配置
    - B. 不自动更新
    - C. 开销小
    - D. 适合大规模网络
    
    **答案：A, B, C**

34. 动态路由的优点是？
    
    - A. 自动更新
    - B. 能适应网络拓扑变化
    - C. 配置简单
    - D. 完全无开销
    
    **答案：A, B, C**

35. ICMP 的主要作用是？
    
    - A. 差错报告
    - B. 测试连通性
    - C. 数据传输
    - D. 路由计算
    
    **答案：A, B**

36. ARP 协议用于？
    
    - A. IP 地址到 MAC 地址映射
    - B. 数据加密
    - C. 路由选择
    - D. TCP 连接管理
    
    **答案：A**

37. 下列关于 NAT 的说法正确的是？
    
    - A. 用于 IPv4 地址复用
    - B. 将私有 IP 转换为公网 IP
    - C. 可以实现防火墙功能
    - D. 用于 TCP 流量加密
    
    **答案：A, B, C**

38. 下列哪种协议属于无连接？
    
    - A. TCP
    - B. UDP
    - C. ICMP
    - D. HTTP
    
    **答案：B, C**

39. 下列哪种协议用于远程管理？
    
    - A. SSH
    - B. Telnet
    - C. FTP
    - D. SMTP
    
    **答案：A, B**

40. 下列属于典型的 LAN 传输介质是？
    
    - A. 光纤
    - B. 双绞线
    - C. 同轴电缆
    - D. 卫星链路
    
    **答案：A, B, C**

### **拥塞控制与其他综合（41-50）**

41. TCP 流量控制机制主要是？
    
    - A. 滑动窗口
    - B. 拥塞窗口
    - C. 超时重传
    - D. CRC 校验
    
    **答案：A**

42. TCP 拥塞控制算法包括？
    
    - A. 慢启动
    - B. 拥塞避免
    - C. 快重传
    - D. 拥塞恢复
    
    **答案：A, B, C**

43. 拥塞发生时，TCP 通常采取措施是？
    
    - A. 减小拥塞窗口
    - B. 增加窗口
    - C. 关闭连接
    - D. 发送 RST
    
    **答案：A**

44. 下列属于无线网络特性的是？
    
    - A. 容易受到干扰
    - B. 传输速率波动大
    - C. 延迟可控
    - D. 移动性强
    
    **答案：A, B, D**

45. HTTP Cookie 主要用于？
    
    - A. 保存会话信息
    - B. 存储文件
    - C. 数据加密
    - D. 控制路由
    
    **答案：A**

46. CDN 的作用是？
    
    - A. 加速内容分发
    - B. 缓解源服务器压力
    - C. 提高访问稳定性
    - D. 提供加密传输
    
    **答案：A, B, C**

47. 下列协议属于应用层协议的是？
    
    - A. DNS
    - B. FTP
    - C. SMTP
    - D. IP
    
    **答案：A, B, C**

48. UDP 不可靠的原因是？
    
    - A. 不保证顺序
    - B. 无确认机制
    - C. 无重传机制
    - D. CPU 占用高
    
    **答案：A, B, C**

49. TCP 可靠性主要通过哪些机制实现？
    
    - A. 序列号
    - B. 确认应答
    - C. 超时重传
    - D. 数据加密
    
    **答案：A, B, C**

50. 下列哪项属于网络性能指标？
    
    - A. 带宽
    - B. 延迟
    - C. 丢包率
    - D. 页面刷新速度
    
    **答案：A, B, C**
