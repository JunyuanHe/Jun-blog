一转眼，已经过去五年了。回想起 2020 年那个暑假，我还只是个大一升大二的学生，怀着几分兴奋和好奇搭建了自己的博客。最开始，我还时不时地写些知识总结；但没过多久，除了后来为数学系的同学搭建了一个习题交流平台，博客就再没更新过了。

<!-- more -->

要说原因，其实也不少。刚开始是因为经济问题，没继续续费云服务器；虽然之后在 GitHub 和 Gitee 上都试过部署网站，但 GitHub 的访问问题一直没解决，Gitee 后来也暂停了 Pages 服务，部署成了一件麻烦事。再后来，学业日益繁重，我常泡在图书馆啃数学书，博客这件事，也就慢慢被我遗忘了。

直到最近，一个偶然的念头让我想做一个个人主页。这一想，忽然又想起了曾经的博客。试着打开旧链接，没想到它居然还能正常访问。只是，GitHub 上只留着部署用的仓库，源码当初保存在本地，换电脑之后也不知丢哪儿了——也许还躺在某块备份硬盘的角落里。留下的，就只剩几篇散落的 Markdown 博文。

四年过去了，变化太多。当年流行的 Web 工具很多还在，但不少已经不是首选。现在 React、Vue 等框架几乎成了标准。我顺手学了学 React，写个纯静态的个人主页练手已经绰绰有余。至于博客生成器，当年我用的是 Hexo，虽然还不错，但也暴露了不少问题。比如 Markdown 渲染不够灵活，尤其是数学公式的支持很折腾人；主题方面也是基于字符串的静态渲染，在交互性和特殊字符支持上都不太理想。接下来我打算找一个更合适的工具，重新构建我的博客。

无论如何，我又回来了，重拾了博客。
至少，这两天，是有内容想写的。
