中午和老师吃完饭散步回来，路上老师偶遇了熟人，聊起了天。年轻的夫妻俩聊起了他们的孩子，上一年级，在旁边的启元上学；黄老师说，他家老二也在启元。话题就这样开始了。

对面夫妻俩中，孩子母亲表示她最近头一次看到孩子的成绩，很难接受，于是开始辅导孩子作业。他们问起了黄老师的孩子的情况，黄老师说：我从来不辅导孩子作业。

“那么是怎么让孩子能学得好呢，有什么经验吗？”

“我会向孩子去灌输，‘学习是你自己的事情，如果作业没做完挨老师批评，好好学考试考得好，这些是你自己的选择，你需要对自己负责’这样一种思想。所以，孩子做学校布置的家庭作业，基本不用我们去操心。我们老二现在二年级，作业从来没有带回家里写过。”

“啊那我们家的不行，做的挺磨蹭了。最近开始辅导孩子，看到他比大小还不会，可着急了。”

“我也不会去辅导孩子功课，我老婆以前老让我辅导孩子数学，但你说，让我们辅导孩子数学，怎么教嘛，这一百以内的加减法，对我们来说都是显然的，没办法教，你越教，自己越着急，你心里就会有情绪。”

“对对对，我教了她也还是不会，我觉得孩子好笨哦。”

“是了，你会觉得孩子笨。可是孩子是很敏感的，她能察觉到你的细微的情绪变化。你心里焦虑，你在否定她，她的心里也是不好受的。”

“我不去辅导，那怎么让孩子学好呢？”

“其实，低年级的时候，成绩是九十还是一百没有那么重要，总会因为粗心大意错上几道题。你只要确保孩子能够跟得上，就可以了。你可以去看看孩子最近几次考试都错了一些什么题目，和孩子一起制定‘提升计划’，比如说在低年级的时候，他口算不行，就每天多做一页口算题。这一页呢，做是他自己的事情，我们不去给他订正，他如果想要对答案，我们就把答案给他让他自己对，错误的题目呢，让他自己想错在哪里了。我们不去过多过问。现在有那种拍照批改的APP，即使没有答案，你帮忙批改也很容易的。”

“学到了，我们希望孩子能够自己养成习惯。”

“是的。我们老大上小学那会儿，上的是另一所学校，那时老师还会让家长检查作业。我们也是不管的。有时候孩子漏做了一两道题，其实这很正常，比如说孩子做了一半出去玩了，回来以后接着写就不小心跳过了一道题。然后第二天老是就在群里联系家长，我们就说，好我们下次会检查的，只要你态度好就可以。但是回家以后，也不必批评孩子，只是提醒他，‘今天你的作业是不是漏掉了一道题呀，下回做完作业记得自己检查一下哦’。我们希望他养成自己检查的习惯，而不是依靠家长。”

“启元还会布置家长伴读的作业，那个是不是也不用做？我觉得那个可费劲了，好像也没什么用。”

“那个恰恰需要做，你可以不用辅导孩子作业，但是一定要陪孩子阅读。这是培养他养成阅读习惯的重要的方式。这就也可以作为一个亲子活动嘛，要不然陪孩子做什么呢？”

（沉思）“那你们一般读些什么呢？”

“读什么都可以，绘本啊，故事书啊，各种类型的都可以尝试。我儿子现在就很喜欢我晚上给他读书，昨天我给孩子读了2本，我老婆读了2本。”

“啊，这么多啊。读的是什么书。”

“读的绘本，那种一本四五十页，读起来很快的，一本十几分钟就读完了。我儿子最近对数学和感兴趣，以前倒是没发现，现在老缠着我给他读数学故事。什么拓扑啊，奇数偶数啊这类的。”

“（笑）这是基因好。”

“也不是要让孩子喜欢数学，他喜欢什么都可以。我们家老大小时候就更爱阅读一些，老二更喜欢我陪他下棋玩益智游戏。但总之，在这些亲子活动中，家长能够带着孩子探索他自己喜欢的东西，也带领孩子培养起好的阅读习惯。”

“看起来我们是彻底搞反了呀！”

“假如孩子面前有几个东西，有书、有游戏机，还有其他一些东西。如果孩子会选择拿起书，而不是果断地拿起游戏，那我们的目的就达到了。重要的方式就是我们带着孩子一起去阅读。”

“嗯我明白了，谢谢老师，今天受益很多。我们需要去培养孩子的习惯，为自己的事情负责的习惯，阅读的习惯。前段时间是看到孩子一位数加减法也不会，比大小也不会，就焦虑了。”

“这个不必着急的，和孩子一起指定一个学习突破计划，坚持两三个月以后，成绩就上来了。我们希望孩子自己去想明白，这种一位数加减法不会，你试图去教他，和他去反复解释，用处是不大的。只有让他多练习，然后突然有一天他自己就弄懂了，顿悟了。这个跟我们有个地方没想懂，有个人给你解释一下，哦，我就懂了，两者是不同的。”

“很有道理。”

“我女儿以前有不会的题目来问我，我都会告诉她，你再想一想，如果十分钟或者半小时以后还没想出来，再来问我。你就在她旁边继续干你自己的事情。很多时候，她都能够自己想出来。”

“诶呀，那我们家的好像不行。你让她过一会儿再来找我，她就觉得你是不在意她，她就出去玩了。”

“讲这个需要一些技巧的。比如说你说这个题目确实是有点难，再想十分钟看看是不是能够想出来？或者鼓励她，我相信你有办法的，再给你一点时间，看看能不能想出来？你需要变着花样引导她自己想。还是想不出来，可以给一点点提示，再交给她自己。”

“嗯嗯，说的是呀。”

“迟早有一天，父母需要放手。我们需要让孩子学会对自己负责，学会计划，培养阅读习惯，学会独立思考。”

......

一旁的我，陷入深思。我之前倒是没有仔细思考过如何教育孩子，不过这样的理念也确实和自己的经历相互印证了。此外，教育是这样，成长其实也是这样。以前的我，习惯整体上还算不错。我喜欢阅读，可是不喜欢写作。小时候老师们也常常提到写作的好处，但是总是被懒惰的我当成负担。但是，我最近恍然理解到，写作是整理思绪的好的方式，也是自省的重要途径，还是让自己与过去的自己对话的最好方式。这不，虽然我写得未必好，也就开始了。
